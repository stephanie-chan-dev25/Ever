# Ever

Ever is a web application for viewing nutritional information and food prices.

## Features
- View nutrients, quantity, and price
- Add foods to a cart and calculate the total
- Search for recipes on the Internet
- Manage data with MySQL

## Technologies
PHP · JavaScript · HTML · CSS · MySQL

## Installation
1. Clone the project.
2. Create the `ever` database.
3. Configure the MySQL connection.
4. Place the project in `htdocs/Ever`.
5. Start Apache and MySQL.
6. Open `http://localhost/Ever`.
